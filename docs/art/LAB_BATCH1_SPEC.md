# Lab Art — Batch 1 Specification (environment kit)

**Status:** proposal; no geometry exists yet. Approval of this file and `ELENA_BLOCKOUT_SPEC.md` authorizes Batch 1 only. Values come from `LAB_STYLE_SPEC.md` and `abandoned_lab.gd` unless marked **[proposed]**.

Conventions (same as `LAB_STYLE_SPEC.md`): GLB, 1 unit = 1 m, +Y up, front/interior = +Z, flat `lab_mat_*` materials, no lights, no cameras, no collision in the file. Source script: `tools/blender/build_lab_environment_kit_batch1.py` **[proposed]**; `.blend` stays outside the repo.

## Checks (`--check`)

- Per asset: AABB size and minimum corner within 1 cm of this table; material names present; palette colors within 0.01.
- Fit tests: 4.0 m frame + 2 × 2.0 m modules per side = 12 m span; opening 2.8 × 3.0 inside the frame.
- Texture: loaded, 512², no import errors.
- Collision rays hit the expected colliders.
