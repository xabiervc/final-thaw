# Milestones

## Milestone 01 — First Playable Loop

### Goal

The player can start the game, perform the core interaction, observe an outcome, and restart.

### Acceptance criteria

- The game starts from a clean checkout.
- The main scene loads without critical errors.
- The player can perform the core interaction.
- The outcome is observable.
- The game can be restarted.
- The README explains how to run and play it.
- The current commit and Godot version are recorded.
