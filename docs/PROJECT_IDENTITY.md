## What this project is

Final Thaw is a Godot game project. This repository contains the playable project, source assets, documentation, tests, development history, and AI-assisted development policies.

## Canonical project rule

The Godot project opened in the editor must be the project whose `project.godot` is located at the repository root. There must be one canonical editable checkout. Other copies are backups, experiments, exports, or temporary workspaces and must be labelled explicitly.

## Repository boundaries

- `project.godot`: Godot project configuration.
- `assets/`: source and runtime game assets.
- `scenes/`: Godot scenes.
- `scripts/`: game code.
- `config/`: project and tooling configuration.
- `data/`: game data and design data.
- `docs/`: design, technical, research, decisions, and development records.
- `tests/`: automated and manual test documentation.
- `prompts/`: reusable AI task prompts, if still needed.
- `schemas/`: structured data schemas.
