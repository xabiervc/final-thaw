## NARRATIVA (Best Narrative contender)

### Character Depth
- [ ] **Elena backstory**: Muerte de Iris (hermana), elección de investigación sobre evacuación, culpa como motivación
- [ ] **Marcus backstory**: Niña Amara murió en disturbios, fracaso como oficial, redención a través de proteger a Elena
- [ ] **Voss backstory**: Hija murió en Mumbai, concluyó "democracia falló al clima", motivación comprensible no villanesca
- [ ] **Arcos completos**: Acto I (huida/supervivencia), Acto II (cooperación/propósito), Acto III (trascendencia/elección)

### Memory Fragments (30 total)
- [ ] **12 Elena**: Infancia con Iris, universidad, elección evacuación, memorial, breakthrough Aster
- [ ] **12 Marcus**: Badge day, primer rescate, orden del Collapse, momento Amara, descarga
- [ ] **6 Voss** (post-game): Mumbai, decisión, primer test, Elena como protegida
- [ ] **Recompensa**: Coleccionar todas = epílogo especial (Iris y Amara sonrientes)

### Diálogo Dinámico
- [ ] **NPCs reactivos**: Civilians rescatados aparecen luego agradeciendo; si no, tono amargo
- [ ] **Elena Safety impacta**: NPCs comentan si "sobrevivió completa" o "algo se rompió"
- [ ] **Marcus estilo**: >70% nonlethal = "protector", >70% lethal = "ejecutor"
- [ ] **Referencias a elecciones**: Shelter rescue, port rescue, evidence choice

### Cinemáticas de Final (90s+ cada una)
- [ ] **Public Thaw**: Earth recovering, Helix disbanded, Aster open-source, Elena en tumba de Iris, Marcus en memorial, niños sin máscaras
- [ ] **Guarded Thaw**: Split screen (zonas protegidas vs exterior), resistencia, Elena desaparece trabajando en fix
- [ ] **Fragile Thaw**: Estabilización parcial, comunidades se adaptan, Elena herida pero determinada, recovery 40 años
- [ ] **Voice acting completo**: Elena (acento europeo del este), Marcus (norteamericano), Voss (cualquier etnia, 50-60)
- [ ] **Música adaptativa**: Piano+cuerdas ascendente (Public), cuerdas sombrías (Guarded), piano solo frágil (Fragile)

### Post-Credits Stinger
- [ ] Earth desde espacio, 3 años después
- [ ] Helix logo crumbling
- [ ] News ticker: "Aster Protocol open-source. 147 nations deploying."
- [ ] Joven científico: "Let's see what we can do better."
- [ ] Implica secuelo/expansión

## GAMEPLAY (Innovation / Best Design contender)

### Puzzles (Portal 2 level)
- [ ] **Estructura**: Enseñar → Probar → Transformar
- [ ] **Sin frame-perfect**: Todas las ventanas son 2+ segundos
- [ ] **Sin aleatoriedad**: Soluciones fijas y legibles
- [ ] **Hint system**: 3 niveles (off, contextual, solución completa)

### Combate (Hades level)
- [ ] **Hitboxes precisas**: Startup, active, recovery frames definidos
- [ ] **Telegraphs legibles**: 0.5-1s antes del ataque
- [ ] **Combos significativos**: Light→light→heavy, light→heavy→launch, heavy→slow→stun
- [ ] **Environmental mastery**: 2-3 objetos lanzables por arena, 1-2 cover ventajosos
- [ ] **Build diversity (NG+)**: Tanque, Agil, Técnico con buffs/debuffs únicos

### Synergy Combos (Innovación clave)
- [ ] **Shield Hack + Flank**: Elena hackea escudo (3s), Marcus flanquea y elimina
- [ ] **Throw to Terminal**: Marcus lanza a Elena 4m para alcanzar terminal
- [ ] **Lighting + Stealth**: Elena controla iluminación, Marcus takedown en oscuro (inmune si lit)
- [ ] **Dual Calibration**: Ambos calibran terminales simultáneos (switching rápido)

### Adaptive Difficulty
- [ ] **Story Mode**: 50% damage taken, 150% dealt, puzzles sin timer
- [ ] **Normal**: Balance estándar
- [ ] **Hard**: Enemigos +25% health, +15% damage, puzzles timer -20%
- [ ] **Nightmare (NG+)**: Enemigos +50% health, +30% damage, hazards 2x
- [ ] **AI adaptativo**: Aprende patrones (pasivo→agresivo, cover→flanqueo, mismo combo→defensa)

## AUDIO (Best Score / Best Audio contender)

### Leitmotifs
- [ ] **Elena**: Piano, cuerdas, ascendente (esperanza/ciencia)
- [ ] **Marcus**: Percusión, brass, rítmico (protección/acción)
- [ ] **Voss**: Coro bajo, sintes oscuros (control/tragedia)
- [ ] **Combinado**: Ambos instrumentos armonizados (Acto III)

### Adaptive Music
- [ ] **0 enemigos**: Minimal (piano solo/ambiente)
- [ ] **1-3 enemigos**: Percusión ligera, cuerdas tenues
- [ ] **4-6 enemigos**: Percusión completa, brass
- [ ] **Boss**: Coro + brass completo, 120+ BPM
- [ ] **Transiciones**: Crossfade 2-3s, nunca corte brusco

### Silence como Herramienta
- [ ] **Momentos clave sin música**: Elena encuentra memoria de Iris, Marcus no mata a Commander, elección final, epílogo Fragile
- [ ] **Solo ambiental**: Viento, agua, maquinaria

### Voice Acting
- [ ] **Elena**: Actriz 28-35, acento europeo del este, restraint pero profundo
- [ ] **Marcus**: Actor 35-45, norteamericano, gravelly pero cálido
- [ ] **Voss**: Actriz 50-60, voz que comanda sin gritar, convencida no villanesca
- [ ] **Dirección**: Dolor en lo que NO dicen, subtexto fuerte

### Sound Design por Enemigo
- [ ] **Scavenger**: Respiración ragged, pasos irregulares
- [ ] **Enforcer**: Servos mecánicos, pasos pesados
- [ ] **Marksman**: Beep targeting, silencio al moverse
- [ ] **Shield**: Campo energético (hum), pasos con eco

## ACCESSIBILITY (BAFTA Accessibility contender)

### Visual
- [ ] **Colorblind modes**: 12 tipos (protanopia, deuteranopia, tritanopia + variantes)
- [ ] **UI scale**: 75%-200% con incrementos de 5%
- [ ] **High contrast mode**: Invierte colores, aumenta bordes
- [ ] **Reduced motion**: Elimina camera shake, reduce partículas 50%
- [ ] **Reduced weather**: Máximo "Moderate" siempre
- [ ] **Screen reader**: Soporte completo menús, diálogos, puzzles

### Audio
- [ ] **Subtitles**: Tamaño 50%-200%, 8 colores, fondo on/off opacidad
- [ ] **Speaker labels**: Nombre + color único por personaje
- [ ] **Visual sound cues**: Indicadores direccionales (pasos, disparos, explosiones)
- [ ] **Audio description**: Narración descriptiva cinemáticas (opcional)
- [ ] **Audio mix**: Presets (Night, TV, Headphones, Surround)

### Motor
- [ ] **Remappable controls**: Cada input reconfigurable (keyboard, mouse, controller)
- [ ] **Toggle/hold**: Cada acción hold puede ser toggle
- [ ] **Auto-run**: Mantener para correr automáticamente
- [ ] **Aim assist**: 0-100% con incrementos de 5%
- [ ] **Slow-motion**: 0.5x, 0.75x, 1.0x (siempre o solo combate)
- [ ] **One-handed scheme**: Layout optimizado una mano

### Cognitive
- [ ] **Puzzle hints**: 3 niveles (off, contextual, solución completa)
- [ ] **Extended timers**: +50%, +100%, ilimitado
- [ ] **Objective marker**: Always-on option
- [ ] **Quest log**: Pasos detallados, opcionalmente simplificados
- [ ] **Minimap**: On/off, tamaño ajustable

### Testing con Gamers Discapacitados
- [ ] **Pre-alpha**: Consultores especializados revisan diseño
- [ ] **Alpha**: Gamers discapacitados prueban 2-3 horas
- [ ] **Beta**: Gamers discapacitados prueban juego completo
- [ ] **Gold**: Certificación (p.ej. AbleGamers seal)

- [ ] **Corruption protection**: Backup automático, recovery

- [ ] **Async loading**: Background con cinemática de transición
